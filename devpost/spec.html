Marketplace Template Filler — Technical Spec

A local Streamlit app in Python. Claude proposes the mapping and checks answers; the output is written by editing the template's XML directly.

How it fits together (click a piece)

One run through the system (PRD core journey)

Why the writer edits the file directly

Result of a test on your blank RING (6).xlsm:

Normal library save (openpyxl)
Dependent dropdowns: 3 → 0
Images: 22 → 1
Size: 1.26 MB → 0.43 MB
Edit only the Template sheet XML
Everything else copied byte-for-byte
Dropdowns, images, hidden sheets kept
Checked by an automated test

Components and PRD links

Upload page — app.pyTwo uploaders and a Start button. Implements prd.md > Upload and reading files.
Template reader — src/template_reader.pyLabels row 4, keys row 5, data from row 8; required flags from Data Definitions; allowed values from Valid Values.
Master reader — src/master_reader.pyLoads the master sheet (608 rows, 36 columns in the sample).
Column mapper — src/mapper.pyName matching first, Claude for the rest; user edits any pair. prd.md > Column mapping.
Question flow — src/questions.pyRequired unmapped columns first; optional columns on request. prd.md > Asking about missing columns.
Validator — src/validator.pyAll rows checked; issues grouped by column. prd.md > Validation and QC.
Template writer — src/xlsm_writer.pyReplaces sheet5.xml only. prd.md > Output.

Failure modes, simplifications, open issues

Failure modes
  • Claude API down / no key → name matching only, manual mapping, rules-only checks with a notice.
  • Unreadable files or missing Data Definitions → plain error, upload again.
  • Output damaged → the writer test fails the step if anything except sheet5.xml changed.
Simplified
  • Questions for required columns by default (not all ~383).
  • Local only, no accounts, nothing saved.
  • Amazon India ring template only.
  • Dependent dropdowns kept intact but not re-evaluated by the checker.
Open for your review
  • Confirm "required columns only by default".
  • Confirm the per-row "depends on a master column" mode.
  • Confirm a small fake sample in samples_public/ for the public repo.
  • These sample files have no VBA macro code; the writer would still copy any macro part unchanged.
