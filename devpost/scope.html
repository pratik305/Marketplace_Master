Marketplace Template Filler

An AI-assisted tool that fills a marketplace upload template (Amazon first) from master product data, asking smart questions for whatever the master lacks.

The unique kernel

The agent doesn't just map columns. After mapping, it interviews you column by column for the missing data, offers the allowed values for dropdown columns, applies answers to all rows or per product/variant, and checks each answer against the template's own rules, so every mandatory column ends up filled and valid.

Who it's for

The listing team. They fill ever-changing, VBA-enabled templates by hand for 100+ products and their variants, typing entries and picking dropdowns. It is slow and error-prone, and then it has to be checked against the rules.

The core loop (click a box or use the step buttons)

What "working" looks like

Amazon template + a master of up to ~500 rows. Upload both, press the button, answer the agent's questions, and download a file in the same VBA-enabled template format, filled in. All mandatory columns are filled and the output satisfies the template's rules.

The "oh, that's cool" beat: hundreds of rows go from mostly empty to complete after a handful of smart questions.

The POC boundary

Now (in the proof of concept)
  • Amazon only; one master + one template per run (~500 rows)
  • Reads the rules sheet and data sheet(s)
  • AI proposes the column mapping
  • Q&A for missing columns: same-for-all or per-row, dropdown choices offered
  • Validation against template rules; all mandatory columns filled
  • Master columns: CODE, BRAND, PLATFORM, CATEGORY, Sku Code/Name, MRP, Selling Price, Sku Size, style ID, weights, diamond details, care, manufacturer, pack contains, origin, color, certificate, metal, Image Url 1-4, gender, description
  • Output keeps the template's format (macros and dropdowns intact)
Later
  • Other marketplaces (Flipkart, Etsy, etc.)
  • Save and reuse mappings and answers across runs
  • Automatic check against the marketplace's own validator
Explicitly cut (proposed, for your review)
  • User accounts, multi-user workflows, deployment: the PoC is for the team to try locally
  • Editing the template's VBA code: macros are preserved, not changed

Why this matters

It removes tedious, mistake-prone work from the team's daily listing job, and it's a chance to get the overall experience of building a real tool end to end.
